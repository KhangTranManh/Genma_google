# B2 / B3 — self-diagnosis with public-differential feedback (31B), sampling with harness filter (12B)

Roadmap steps B2 and B3 (method 26). Same issue w3lib_264, sanitized issue, source block, tool schema, 16K runtime, thinking off, output cap 1536.
Every patch call goes through the B1 edit guard (at most one mechanical re-ask, not counted as an attempt). The host applies exact replacement.

Grading (`scripts/b23/evaluate.py`):
- **Public**, which the harness may use and which is shown in B2 feedback: reproducer `"<base "*6000` median ≤ 0.2 s; 67 functional tests; public differential (plain HTML must equal the ORIGINAL implementation; up to 3 disagreement examples).
- **Hidden**, never shown: independent regression grader, long-attribute semantic check, hidden differential (original or upstream).
- `accepted` = public pass and every hidden check.
- Per-batch preflight: the original fails public, the upstream reference is accepted.

## B2 — 31B (batch `runs/b2-selfdiag-v1/31b`)

Two arms × 4 trajectories (temp 0; temp 0.6 with seeds 17/29/43):

| Arm | First hint | Then |
|---|---|---|
| `selfdiag_G` | Diagnose call (no tools, ≤ 512 tokens, JSON span/failing_condition/complexity/why) from issue + source + public timing of the original at n = 1000/2000/4000 | Checklist G (frozen v2 text) |
| `hostA_G` | Host-written mechanism A (reference for the effect of feedback) | Checklist G |

Up to 2 patch rounds per trajectory. Round 1 runs only if round 0 fails the public checks. The model sees its previous call and the public results, including the differential examples (input, original output, its output). Stop on public pass.
Report accepted after round 0 and after the final round. The noTiming ablation of the roadmap is deferred.

## B3 — 12B (batch `runs/b3-sampling-v1/12b`)

Prompts ABC (hint ladder v1) and AG (hint ladder v2). 6 samples each, temp 0.6, seeds 1–6, with guard.
The harness selects the first sample (in seed order) that passes all public checks. All samples are also graded hidden for audit only; selection never uses hidden results.

## Limits

One issue. Hint G was written after seeing this issue, and A is host-written. The public differential is derived from the original code only, so it carries no answer key.
B2 feedback adds a call and tokens, so it is not equal-budget with hint ladder. No cross-model table. No Kaggle submission.
