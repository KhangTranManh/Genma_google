# B4 v2 — 31B with per-function public checks and adaptive sampling

This method follows B4 v1 (method 28). The tasks, sanitized issues, excerpts, Diagnose and Patch templates, checklist G and hidden graders are unchanged. 12B is dropped for this bug class after 0/18 in v1.

What changes:

1. **Per-function public reproducer.** Every function named in the issue gets its own reproducer, at its own calibrated N, where the original takes ≥ 0.5 s. The public check passes only if every function is fast. For w3lib_268 these are `replace_tags` at N=8000 and `remove_tags` at N=1000. Preflight: the reference passes both; the v1 31B t0 candidate fails both.
2. **Adaptive sampling.** Up to 8 samples per task, in a fixed order (t0, then seeds 17/29/43/5/11/23/31). The task stops at the first sample whose final candidate passes all public checks.
3. **One feedback round per sample.** If round 0 fails the public checks, or its edit is rejected, the sample gets exactly one more Patch call on the cumulative source. That call is shown:
   - the per-function timings,
   - the functional test tail,
   - up to 3 behavior-vs-original examples,
   - the previous calls.

   Hidden results are never shown.

Batch `runs/b4-v2/31b`; report `reports/b4-v2/31b`. v1 results are not modified. B2 showed that feedback can regress, so round-0 and final acceptance are both reported.
