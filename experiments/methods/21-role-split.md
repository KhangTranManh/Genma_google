# Role split v1 — one model, isolated calls, Python selection

Same12B/31B local checkpoints, issue w3lib_264 solution-redacted, supplied source excerpts (first40 lines + get_base_url body), native API,temperature0,thinkingoff,16K window. Not autonomous repository localization and not competition score. Each model has up to7 calls: Localize1536 +3 patches1536 +3 feedback verdicts384 (max7296 generated tokens/model), a larger budget than A/B/C. Do not claim equal-budget improvement.

Localize: fresh messages, no tools, strict structured JSON withK3 causal hypotheses, location and observable failure prediction. Host validates exact3, unique IDs, valid source ranges; invalid output stops needs_review rather than silently fabricating hypotheses. No hidden patch or fixed expression in model inputs. Distinct IDs do not ensure semantic diversity; inspect actual hypotheses.

Python ranking: baseline uninstrumented performance reproducer must fail. Collect line coverage of SAME input6000 separately via Python trace (instrumented timing not used for failure label), plus5 passing URL cases. Calculate max per-line Ochiai across each proposed range; rank descending, stable original order on ties. Single failing input,5 passing inputs, source file only, no exception stack trace. Regex definitions compiled at import may not appear in call coverage; absence of coverage is not causal refutation. Scores correlate location, cannot distinguish hypotheses at same lines or validate natural-language causal predictions. Preserve all3 for patching regardless of ranking.

Patch: only assigned hypothesis, issue, original code; fresh messages without Localize conversation or other hypotheses. One edit_file call,1536 output. Semantic fidelity to assigned hypothesis is an instruction, not a formally verified guarantee. Raw/API same-generation capture and independent execution on two original clean Docker snapshots. No cumulative edits between hypotheses. Invalid/truncated call consumes budget; source unchanged. Role is tool-restricted; no shell access.

Public observations v2: original67 functional tests with JUnit counts, public performance reproducer6000, plus semantic guard valid tags with extra attribute lengths0/200/1000. Guard added before this run based on earlier audit; grader version differs from earlier arms. Preflight base must fail only performance and diagnostic fixed must pass all. Public-check infrastructure errors are inconclusive, stop rather than count ordinary failure.

Python retention: diff nonempty, not an exact duplicate diff, failure_count strictly decreases, zero functional regression, semantic guard pass AND all public checks pass. Because baseline has only1 failing check, meaningful progress here equals full public pass; no credit for noisy runtime fluctuations. No-progress limit1 patch/hypothesis. Rollback = discard container, never carry rejected source forward. Python eliminates duplicate/no-progress hypotheses; keeps objective-passed patches in retained set. Exact diff hashes do not detect all semantic-equivalent patches.

Feedback role: fresh messages contain ONLY assigned hypothesis and compact objective observations (no patch, no writer history, no other hypotheses), no tools; schema supported/rejected/uncertain +brief evidence/uncertainty. Verdict is archived but NEVER controls retain/eliminate/select. Roles use the same checkpoint with no session/KV conversation reuse at application level; server may reuse prefix cache, which is not a conversational memory. No claim role separation removes all self-evaluation bias.

Python selects from retained public-pass patches by median public runtime, diff size, stable index. No retained patch => no submission, no artificial best failure. Independent grade applied once ONLY to selected API candidate: method18 frozen regression2K/4K/8K/30K + valid URL assertions + extra valid attributes300/1500. Independent result cannot grant retry, choose another patch, or leak to feedback role. Optional pairwise A/B comparator not implemented in this first version; no need for another model.
