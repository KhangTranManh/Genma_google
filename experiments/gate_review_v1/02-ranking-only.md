# 2. Prediction ranks attempts; tests decide patch acceptance

Status: defined, standalone ranking helper implemented/tested; no model run. Default replaces prediction rejection with ordering only. Hypotheses with prediction errors remain in queue. Missing/uncertain predictions are not false outcomes; structurally invalid hypotheses need a separate logged handling path, never guessed repairs.

Deterministic ordering: more decisive matches, fewer contradictions on declared public diagnostic observations, then weak source-evidence/Ochiai, original stable index. Freeze prediction/evidence versions before ordering; exclude hidden final grader and held-out transfer measurements until their declared reveal phase. Every valid trajectory gets at least one Patch attempt when budget>=1, even if all hypotheses are weak. Original-source patch each time, no writer context reuse. Strictly retain only public reproducer pass +zero functional/semantic regression; no gain from tiny timing noise. No retained candidate means no submission. One independent final grade of the publicly selected candidate; evaluator can inspect other candidates only in the separate audit, without affecting selection.

Controls for matched candidate pool: original order, old gate, rank-only; patch budgets1/2/3. No changes to prompt/model/grader while isolating ordering. If live measurement is later needed, compare same task splits/seeds, report actual token/time costs. Prediction score is a heuristic scheduling signal, NOT a correctness score.

Optional severe-contradiction flag: >=3 decisive contradictions AND >=4 decisive observations AND contradiction ratio>=0.75, using only the named public-known probe set. Example1/4 matches is flagged. A single transfer-prediction miss out of6 is not severe. Flag initially changes neither eligibility nor count; hard elimination disabled. Enabling hard elimination requires the P0 audit and another measured ablation. It may still discard a good patch and must keep audit coverage. No destructive prune based on an unvalidated flag.
